# Helix Drop

Hold to smash a ball down through a spinning tower. Let go before a dark floor, or the run ends. Finish levels to earn coins and spend them on new balls in the shop. Every level has its own colors and a twist: spinners, sliders, glass floors, turbo speed, boss levels and more.

Play it at https://brandrisk4.github.io/helix-drop/ and add it to your home screen:

- **iPhone (Safari):** tap Share, then "Add to Home Screen".
- **Android (Chrome):** tap the ⋮ menu, then "Install app".

It works offline after the first load. If you change any file, bump `VERSION` in `sw.js` so installed copies update.
